## פרסום ב־GitHub Pages

המאגר כולל workflow לפרסום אוטומטי. ב־GitHub יש לבחור:

1. `Settings` → `Pages`.
2. תחת `Build and deployment`, לבחור `GitHub Actions` כמקור הפרסום.
3. לדחוף את ענף `main`; ה־workflow יפרסם את תוכן המאגר.

כל הנתיבים יחסיים ולכן האפליקציה פועלת גם תחת נתיב המאגר, לדוגמה:
`https://username.github.io/EMT_ASHDOD_497/`.

### הוספת שאלה

בקבצי הנתונים התשובה הנכונה כתובה תמיד ראשונה, והאתר מערבב את הסדר. לכל תשובה שגויה כותבים הסבר קצר במערך האחרון, לפי אותו סדר.
כדאי שכל התשובות יהיו באורך ובפירוט דומים, כדי שהתשובה הנכונה לא תבלוט.

### בנק הטעויות

שאלה שנענתה לא נכון נכנסת לבנק. היא יוצאת ממנו אחרי שלוש תשובות נכונות בשלושה ימים שונים.

## PWA ועדכונים

ה־service worker שומר את כל קובצי המשחק המקומיים לשימוש לא מקוון. בעת שינוי קובצי האתר יש לעדכן את `CACHE_VERSION` בתוך `sw.js`, כדי שהגרסה החדשה תחליף את המטמון הקודם.

## מניעת אינדוקס

בכל דף HTML מוגדרת הוראת `noindex`, ובנוסף קיים `robots.txt`. אין לראות בכך בקרת גישה: אתר GitHub Pages ציבורי עדיין נגיש לכל מי שמחזיק בקישור.
